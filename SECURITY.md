# Security

## Reporting

To report a security vulnerability, open a private issue at
https://github.com/dmzoneill/securetty/security/advisories/new
or email dmz.oneill@gmail.com.

## Threat Model

See [THREAT_MODEL.md](THREAT_MODEL.md) for the full 8-section threat assessment including assets, entry points, threats, and mitigations.

Only the latest commit on `main` is supported.
